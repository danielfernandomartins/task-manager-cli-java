# ✅ Task Manager CLI em Java

Gerenciador de tarefas executado no terminal para praticar orientação a objetos e manipulação de coleções.

## Funcionalidades

- Adicionar tarefa
- Listar tarefas
- Marcar como concluída
- Remover tarefa

## Tecnologia

**Java**

## O que demonstra

- Classes e objetos
- Listas
- Controle de estado
- Métodos
- Fluxo de menu

## Visão para Operações de TI

O projeto trabalha com mudança de estado, algo recorrente em ferramentas de chamados e rotinas operacionais: aberto, em andamento, concluído e removido.

## Como explicar em entrevista

> "Usei um gerenciador de tarefas para entender melhor controle de estado. Em suporte e operações, isso aparece o tempo todo em chamados e processos. O projeto me ajudou a pensar em estado atual, ação permitida e resultado esperado."
